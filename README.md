# EduTrack — Student Performance Analysis System

EduTrack is a web-based application for managing student details, recording marks, viewing academic results, and analyzing student performance.

## Features
- Student management
- Marks entry, editing, and deletion
- Results and grade analysis
- Dashboard with performance statistics
- Analytics and visualizations
- MySQL database integration

## Technologies Used
- Python
- Flask
- MySQL
- Pandas
- NumPy
- Matplotlib
- HTML and CSS

## Running Locally
1. Install Python and MySQL.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure the database environment variables in `.env`.
4. Create the `student_performance_db` database and required tables.
5. Run `python app.py` and open the local address displayed in the terminal.

**Note:** Database setup and environment configuration are required before running the application.
